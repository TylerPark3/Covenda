# Covenda: Alan Zhang Strategy Pack

This pack converts Alan Zhang's feedback into a practical GStack and customer-discovery workflow.

## Run order

1. Save the folder inside the Covenda repository under `docs/advisor-feedback/alan-zhang/`.
2. Run `/office-hours` and paste `02_OFFICE_HOURS_PROMPT.md`.
3. Review the resulting strategy documents.
4. Run `/plan-ceo-review` and paste `03_CEO_REVIEW_PROMPT.md`.
5. Begin the 30-interview campaign using files 04–07.
6. Do not build a vertical-specific product until the interviews validate the wedge.
