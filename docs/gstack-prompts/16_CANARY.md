# CANARY

> Source: Covenda GStack Prompt Pack. Paste into the matching GStack skill.

Monitor the Covenda production deployment as a canary.

Watch the affected routes and workflows for:

- console errors;
- failed network requests;
- elevated latency;
- broken auth;
- RLS denials for valid users;
- cross-tenant exposure;
- duplicate submissions;
- missing audit events;
- upload failures;
- layout regressions;
- mobile failures;
- accessibility regressions;
- unexpected cost or query-volume spikes.

Use both a normal account and a deliberately unauthorized path where safe.

Report:

- health status;
- observed errors;
- user impact;
- rollback recommendation;
- follow-up issues.
