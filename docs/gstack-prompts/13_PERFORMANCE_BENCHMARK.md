# PERFORMANCE BENCHMARK

> Source: Covenda GStack Prompt Pack. Paste into the matching GStack skill.

Benchmark the affected Covenda routes before and after this feature.

Measure:

- page load;
- Core Web Vitals;
- JavaScript and CSS size;
- image and font weight;
- API latency;
- Supabase query count;
- duplicate requests;
- evidence-list rendering;
- graph or visualization rendering if affected;
- mobile performance;
- authenticated-route performance.

Use realistic seeded data, including:

- a student with many evidence items;
- a company with multiple Talent Briefs;
- a shortlist with enough candidates to expose scaling issues.

Identify regressions, establish a baseline, and propose fixes only when they preserve correctness and accessibility.
