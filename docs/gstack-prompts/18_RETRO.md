# RETRO

> Source: Covenda GStack Prompt Pack. Paste into the matching GStack skill.

Run a Covenda engineering and product retrospective for the completed sprint.

Read the approved plans, merged pull requests, QA reports, production incidents, and `docs/COVENDA_GSTACK_CONTEXT.md`.

Evaluate:

- what shipped;
- what produced user value;
- where the blueprint helped;
- where the blueprint created unnecessary scope;
- defects caught by review, QA, or production;
- test-health trend;
- security and privacy debt;
- accessibility debt;
- repeated manual work worth productizing;
- premature automation;
- gaps in the decision ledger;
- founder decisions that should become durable project rules.

End with:

1. keep;
2. change;
3. stop;
4. next sprint objective;
5. one measurable product assumption to test;
6. learnings to save through `/learn`.
